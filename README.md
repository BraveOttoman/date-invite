# Date Invite 💌

A little animated website to ask someone special out on a date.

1. Open the envelope
2. Say yes (the "No" button runs away 😉)
3. Pick a date idea: the background changes to match
4. Pick a day on the calendar (special days get a heart or a cake)
5. Get a confirmed date ticket 🎟️

Everything is in `index.html`. Change names, date ideas, special days and times in the `✏️ CUSTOMIZE HERE` block near the top of the `<script>`.
